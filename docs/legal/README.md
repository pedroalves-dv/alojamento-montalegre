# Legal registrations

What each house is registered as, and the numbers the site must show. The scans themselves live
in `docs/legal/private/`, which is git-ignored: they carry personal data (taxpayer numbers,
email addresses) and this repository is public. Keep a second copy outside this computer
(e.g. Google Drive).
